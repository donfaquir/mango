# MS6: 配音 + 成片闭环

## 迭代目标

补齐"声音"维度，实现从剧本到带配音成片的完整创作闭环。

**预估工时**：30-45 小时（~3 周）

**前置依赖**：MS5（需要视频编辑能力）

---

## 任务清单

### 任务 1：AI 配音 Provider 接入

**任务描述**：复用 ModelProvider trait 架构，适配 TTS 类型的 Provider。

**开发概设**：
- 扩展 ModelProvider trait 或新建 TTSProvider trait
- GenerationParams 扩展：voice_id, text, speed, emotion 等 TTS 参数
- 选型候选：MiniMax / ChatTTS / FishSpeech（选择 API 最稳定的一家首先接入）
- 输出：音频文件（mp3/wav）

**验收标准**：
- [ ] 可提交 TTS 任务并获取音频结果
- [ ] 支持指定音色（voice_id）
- [ ] 支持调整语速
- [ ] 错误处理覆盖常见场景

---

### 任务 2：候选配音服务选型

**任务描述**：调研并确定首个接入的 TTS 服务。

**开发概设**：
- 评估维度：API 稳定性、音色质量、中文支持、价格、延迟
- 候选：MiniMax Speech、ChatTTS (自部署)、FishSpeech、Edge TTS
- 输出选型报告，确定首选和备选

**验收标准**：
- [ ] 有明确的选型结论和理由
- [ ] 首选服务 API 可正常调通
- [ ] 音色质量满足漫剧配音需求

---

### 任务 3：角色声音绑定

**任务描述**：为角色绑定固定音色，实现角色级别的声音一致性。

**开发概设**：
- Character 表扩展 voice_id 字段
- 角色编辑页增加音色选择/试听
- 音色列表：从 TTS Provider 获取可用音色列表
- 试听功能：选择音色后可用示例文本试听

**验收标准**：
- [ ] 可为角色绑定音色
- [ ] 音色选择时可试听效果
- [ ] 绑定后生成配音时自动使用该音色
- [ ] 更换音色后可重新生成配音

---

### 任务 4：配音生成流程

**任务描述**：从分镜对白文本自动生成配音音频。

**开发概设**：
- 提取分镜 dialogue 字段文本
- 根据角色查找绑定的 voice_id
- 提交 TTS 任务 → 轮询 → 下载音频 → Asset 入库
- 支持单分镜生成和批量生成（全集所有对白）

**验收标准**：
- [ ] 单个分镜可生成对应的配音音频
- [ ] 批量生成全集配音
- [ ] 生成的音频 Asset 正确关联到分镜
- [ ] 无对白的分镜自动跳过

---

### 任务 5：音效素材库

**任务描述**：提供音效素材的管理功能。

**开发概设**：
- 内置基础音效：打斗、脚步、环境音等（首版可少量）
- 用户自定义导入：支持 mp3/wav/ogg 音效文件导入
- 音效分类：环境、动作、UI、情感
- 音效预览：点击即播

**验收标准**：
- [ ] 内置音效可浏览和试听
- [ ] 可导入自定义音效文件
- [ ] 音效按分类组织
- [ ] 点击可快速预览

---

### 任务 6：分镜音效匹配 UI

**任务描述**：为分镜选择和绑定背景音效。

**开发概设**：
- 分镜详情中增加音效绑定区域
- 从音效库中选择 → 绑定到分镜
- 支持设置音效音量、起始偏移
- 一个分镜可绑定多个音效（叠加）

**验收标准**：
- [ ] 可为分镜绑定音效
- [ ] 可调整音效音量
- [ ] 支持多个音效叠加
- [ ] 绑定后可预览效果

---

### 任务 7：音画对齐

**任务描述**：处理配音时长与视频时长的匹配问题。

**开发概设**：
- 检测：比较配音时长和视频片段时长
- 策略 1：配音短于视频 → 末尾填充静音
- 策略 2：配音长于视频 → 提示用户调整语速或裁剪
- 策略 3：调整语速参数重新生成
- 可视化：时间轴上显示音视频时长对比

**验收标准**：
- [ ] 自动检测音视频时长差异
- [ ] 短配音自动填充静音
- [ ] 长配音给出可操作的建议
- [ ] 对齐结果可预览

---

### 任务 8：最终合成

**任务描述**：将视频 + 配音 + 音效 + 字幕合成为最终成片。

**开发概设**：
- FFmpeg 混合：多路输入流（视频轨 + 配音轨 + 音效轨）
- 字幕叠加：ASS/SRT 烧录
- 音频混合：配音 + 音效按各自音量混合
- 输出参数：可配置分辨率、码率、格式

**验收标准**：
- [ ] 输出视频包含所有元素（画面 + 配音 + 音效 + 字幕）
- [ ] 音画同步准确
- [ ] 多音轨混合音量合理
- [ ] 输出格式和质量可配置

---

### 任务 9：导出设置 UI

**任务描述**：实现成片导出的参数配置界面。

**开发概设**：
- 分辨率选项：1080p / 720p / 自定义
- 码率选项：高/中/低 或自定义值
- 格式选项：MP4 (H.264) / WebM (VP9)
- 预估文件大小显示
- 导出进度条

**验收标准**：
- [ ] 可选择导出参数
- [ ] 预估文件大小合理
- [ ] 导出过程显示进度
- [ ] 导出完成后可直接打开文件位置

---

### 任务 10：CLI 最终导出命令

**任务描述**：实现 CLI 下的成片导出命令。

**开发概设**：
- `mango export final --episode ep01 --output ./output.mp4`
- 可选参数：`--resolution 1080p --bitrate 8M --format mp4`
- 进度输出到 stderr
- 完成后输出文件路径和大小

**验收标准**：
- [ ] CLI 导出与 GUI 导出结果一致
- [ ] 参数配置与 GUI 选项对齐
- [ ] 进度输出友好

---

## 迭代交付物

- AI 配音集成（至少 1 家 TTS Provider）
- 角色声线绑定 + 批量配音生成
- 音效匹配
- 最终成片导出

## 演示验收

> 为角色"小明"选择少年音色 → 一键为全集对白生成配音 → 为打斗分镜添加音效 → 点击"导出成片" → 得到一个带对白配音、背景音效和字幕的完整短视频 → MVP 全流程闭环
