# MS6: 配音 + 成片闭环

## 迭代目标

补齐"声音"维度，实现从剧本到带配音成片的完整创作闭环。

**预估工时**：44–60 小时（~4–5 周，拆 5 个 spec）

**前置依赖**：MS2（task engine + provider 架构）；MS5（FFmpeg sidecar + 视频导出 pipeline）

## 关键设计修正（相对原始任务书）

1. **不新建独立 Provider 模块** — 在现有 `BailianProvider` 中追加 cosyvoice-v2 路由（同 wan2.7 模式）
2. **统一百炼服务** — 不接入 MiniMax/即梦等外部 TTS；复用现有百炼账号
3. **砍掉内置音效** — local-first 桌面应用不宜打包音频资源；只做用户导入 + 标签分类
4. **新增 FFmpeg 音频基础设施（spec-40）** — 现有 ffmpeg 模块零音频操作，最终合成需要 filter_complex 支持
5. **新增 shot_audio 数据模型** — 原任务书缺失音效到分镜的关联表设计
6. **Export v2 扩展现有 pipeline** — 非独立路径，在 `export.rs` 基础上增加音频轨合成
7. **字幕烧录延后** — ASS 渲染复杂度高，移至 MS7

## 迭代交付物

- AI 配音集成（百炼 CosyVoice 2.0）
- 角色声线绑定 + 批量配音生成
- 用户音效导入 + 分镜音效绑定
- FFmpeg 音频混合/对齐基础能力
- 最终成片导出（视频 + 配音 + 音效）

## 演示验收

> 确认百炼账号已配置（复用现有） → 为角色"小明"选择少年音色 → 一键为全集对白生成配音 → 为打斗分镜导入音效并绑定 → 调整音量偏移 → 点击"导出成片" → 选择 1080p / MP4 / 全部音轨 → 导出完成 → 播放确认画面+配音+音效同步 → CLI `mango export final` 产出相同结果
