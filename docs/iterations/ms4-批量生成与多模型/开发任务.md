# MS4: 单 Provider 下多模型 + 批量 + 版本管理

## 迭代目标

在百炼单 Provider 体系下支持多模型对比选择和批量生成，实现"抽卡"式创作流程，并引入版本管理保护创作成果。

**预估工时**：40–55 小时（~3–4 周，拆 7 个 spec 后修订）

**前置依赖**：MS2（任务引擎 + 百炼 Provider）；**软依赖** MS3 spec-20（分镜）、spec-24（检查点占位）

## 演示验收

> 选中第三集全部 8 个分镜 → 在百炼下选择两个模型各生成一次 → 16 个结果并排对比 → 逐个选择最佳 → 点击"保存版本" → 标记为"分镜定稿" → 继续修改 → 发现改坏了 → 恢复到"分镜定稿"版本

逐项勾选见 [验证清单.md](验证清单.md)。
