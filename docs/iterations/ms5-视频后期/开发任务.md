# MS5: FFmpeg 基础与视频剪辑

## 迭代目标

集成 FFmpeg sidecar，封装视频裁剪/分割/拼接基础命令，构建单轨时间轴裁剪 UI 和片段编排导出界面，使用户能够对 AI 生成的视频素材进行简单的后期剪辑并导出成片。

**预估工时**：38–50 小时（~3–4 周，拆 5 个 spec）

**前置依赖**：MS2（需要已生成的视频素材）；**软依赖** MS4 spec-28（`adopted_asset_id` 作为默认片段来源）

### 建议 PR 实施顺序

见 [dependencies.md §7](dependencies.md#7-建议-pr-实施顺序)。

```
spec-32 (FFmpeg sidecar + probe)
    └─▸ spec-33 (video commands)
            └─▸ spec-34 (progress parsing + events)
                    └─▸ spec-35 (timeline UI)
                            └─▸ spec-36 (clip assembly + export)
```

线性依赖链：每层构建在前一层之上。spec-35 的纯 UI 部分（手柄、刻度尺、播放头）可与 spec-34 并行开发，集成测试时需要 spec-34 完成。

## 迭代交付物

- FFmpeg sidecar 集成（二进制发现、健康检查、视频探测）
- 视频裁剪/分割/拼接命令封装 + 缩略图抽取
- FFmpeg 进度解析与实时推送
- 单轨时间轴 UI + 裁剪交互
- 片段编排 + 拼接导出 + CLI `mango export clip`

## 演示验收

> 打开一个包含 3 个已生成视频片段的项目 → 检查 FFmpeg 状态（绿色可用）→ 探测视频元数据 → 进入视频编辑器 → 时间轴加载缩略图条 → 拖动裁剪手柄截取 2s-8s 片段 → 添加 3 个片段到编排列表 → 拖拽调整顺序 → 点击导出 → 进度条实时更新 → 播放导出视频，连续无卡顿

逐项勾选见 [验证清单.md](验证清单.md)。
