# MS5: 视频后期

## 迭代目标

将 AI 生成的视频片段裁剪、拼接、叠加字幕和漫画气泡，产出可观看的连续视频段落。

**预估工时**：40-60 小时（~4 周）

**前置依赖**：MS2（需要已生成的视频素材），建议在 MS4 之后进行

---

## 任务清单

### 任务 1：FFmpeg sidecar 集成

**任务描述**：集成 FFmpeg 作为 sidecar 二进制，管理其生命周期。

**开发概设**：
- 使用 `ffmpeg-sidecar` 2.5+ crate 管理 FFmpeg 进程
- Tauri `externalBin` 配置嵌入 FFmpeg 二进制
- 开发环境通过 PATH 查找系统 FFmpeg
- 提供 FFmpeg 可用性检查函数

**验收标准**：
- [ ] 开发环境下正确找到系统 FFmpeg
- [ ] Tauri 打包后 FFmpeg sidecar 正常工作
- [ ] FFmpeg 不可用时给出明确错误提示
- [ ] 进程异常退出时正确处理

---

### 任务 2：视频裁剪命令封装

**任务描述**：封装 FFmpeg trim 命令，支持指定起止时间裁剪。

**开发概设**：
- 输入：源文件路径、起始时间、结束时间、输出路径
- FFmpeg 命令：`-ss start -to end -c copy`（无需重编码的快速裁剪）
- 需要精确裁剪时使用重编码模式
- 返回输出文件路径

**验收标准**：
- [ ] 可按时间点裁剪视频
- [ ] 快速模式（copy）和精确模式均可工作
- [ ] 输出文件可正常播放
- [ ] 时间参数校验（start < end, end ≤ duration）

---

### 任务 3：视频分割命令封装

**任务描述**：封装 FFmpeg split 命令，按时间点将视频切割为多段。

**开发概设**：
- 输入：源文件路径、分割时间点列表、输出目录
- 产出多个视频片段文件
- 自动命名：`{原名}_part1.mp4`, `{原名}_part2.mp4`

**验收标准**：
- [ ] 可按多个时间点分割视频
- [ ] 各片段可独立播放
- [ ] 片段总时长等于原视频时长

---

### 任务 4：视频拼接命令封装

**任务描述**：封装 FFmpeg concat 命令，将多个片段按顺序合并。

**开发概设**：
- 输入：视频文件路径列表（有序）、输出路径
- 使用 concat demuxer 或 filter_complex 实现
- 处理不同分辨率/帧率的片段（统一转码）

**验收标准**：
- [ ] 可将多个片段拼接为一个视频
- [ ] 输出文件连续播放无卡顿
- [ ] 相同参数的片段使用快速 concat
- [ ] 不同参数的片段自动转码对齐

---

### 任务 5：进度解析

**任务描述**：解析 FFmpeg stderr 输出，提取处理进度百分比。

**开发概设**：
- 解析 FFmpeg 输出中的 `time=` 字段
- 结合源视频总时长计算进度百分比
- 通过 channel 推送进度更新
- GUI 模式通过 Tauri event 推送到前端

**验收标准**：
- [ ] 进度百分比准确（误差 < 5%）
- [ ] 进度更新频率合理（每秒 1-2 次）
- [ ] 前端进度条平滑更新

---

### 任务 6：基础时间轴 UI

**任务描述**：实现单轨时间轴，支持可视化裁剪。

**开发概设**：
- 单轨时间轴组件：显示视频帧预览条
- 裁剪标记：可拖动的起止点标记
- 时间刻度：跟随缩放级别显示
- 播放头：当前播放位置指示器
- 视频预览同步：拖动时间轴时预览画面跟随

**验收标准**：
- [ ] 时间轴正确显示视频时长
- [ ] 可拖动起止标记设置裁剪范围
- [ ] 时间刻度随缩放调整
- [ ] 预览画面与时间轴同步

---

### 任务 7：片段排序 UI

**任务描述**：实现拖拽调整视频片段拼接顺序的界面。

**开发概设**：
- 片段列表：纵向排列，显示缩略图 + 时长
- 拖拽排序：HTML5 DnD 或 dnd-kit
- 操作按钮：添加片段、移除片段、预览拼接结果
- 执行拼接：调用后端 concat 命令

**验收标准**：
- [ ] 可拖拽调整片段顺序
- [ ] 可添加/移除片段
- [ ] 执行拼接后得到正确顺序的输出视频
- [ ] 拼接过程中显示进度

---

### 任务 8：漫画对话框/旁白气泡叠加

**任务描述**：实现在视频上叠加漫画风格对话框和旁白气泡。

**开发概设**：
- 气泡类型：对话气泡、旁白框、心理活动云朵
- 编辑：文本输入 + 字体/大小选择 + 气泡样式选择
- 定位：在视频画面上拖动调整位置
- 时间范围：设置气泡显示的起止时间
- 实现方式：FFmpeg drawtext filter 或 ASS 字幕叠加

**验收标准**：
- [ ] 可添加多种样式的对话气泡
- [ ] 气泡位置可拖动调整
- [ ] 可设置气泡显示时间范围
- [ ] 导出视频中气泡正确显示

---

### 任务 9：字幕烧录

**任务描述**：支持 SRT 格式字幕烧录到视频中。

**开发概设**：
- 输入：SRT 字幕文件或手动编辑的字幕数据
- FFmpeg 实现：drawtext filter 或 ASS filter
- 字幕样式：字体、大小、颜色、描边、位置可配置
- 字幕编辑器：简单的时间轴对齐字幕文本

**验收标准**：
- [ ] 可导入 SRT 字幕文件
- [ ] 字幕正确叠加到视频上
- [ ] 字幕样式可自定义
- [ ] 字幕时间与视频画面对齐

---

### 任务 10：项目文件备份

**任务描述**：实现 SQLite 文件级别的项目备份与恢复。

**开发概设**：
- 利用 SQLite backup API 复制完整数据库文件
- 备份存储：项目目录下 `backups/` 子目录
- 备份命名：`project_YYYYMMDD_HHmmss.db`
- 恢复：替换当前数据库文件（重启连接）

**验收标准**：
- [ ] 备份文件完整可用
- [ ] 恢复后项目数据回到备份时状态
- [ ] 备份期间不影响正常使用
- [ ] CLI 和 GUI 均可触发备份

---

### 任务 11：CLI 导出和备份命令

**任务描述**：实现 CLI 下的视频导出和备份命令。

**开发概设**：
- `mango export clip --input a.mp4 --start 00:05 --end 00:15 --output clip.mp4`
- `mango backup create --project <id>`
- `mango backup restore <backup_file>`
- `mango backup list --project <id>`

**验收标准**：
- [ ] CLI 裁剪命令正常工作
- [ ] 备份命令创建有效的备份文件
- [ ] restore 有确认提示
