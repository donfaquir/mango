# MS5 验证清单

> 对应演示故事：`docs/iterations/ms5-视频后期/开发任务.md` §演示验收。
> 按 [dependencies.md](dependencies.md) 建议顺序分 spec 勾选；全部通过视为 MS5 闭幕。

**前置**：MS2 百炼单任务可用（需要已生成的视频素材）；开发环境 FFmpeg 已安装（`ffmpeg -version` 可执行）。

---

## spec-32 FFmpeg sidecar

- [ ] `check_ffmpeg` 返回 `available=true` + 正确版本号
- [ ] `probe_video` 对 mp4/webm 文件返回正确的时长、分辨率、编解码器
- [ ] FFmpeg 不可用时 `check_ffmpeg` 返回 `available=false`，不 panic
- [ ] `MANGO_FFMPEG_PATH` 环境变量被正确使用
- [ ] core crate 无 Tauri API 依赖（`cargo build -p mango-core` 不报错）

## spec-33 视频操作命令

- [ ] `trim_video` Copy 模式输出可播放，时长约等于指定范围
- [ ] `trim_video` Reencode 模式裁剪精确到帧
- [ ] Reencode 对无音轨视频不报错（自动 `-an`）
- [ ] 非法时间参数（start >= end, end > duration）返回明确错误
- [ ] `split_video` 产出文件数 = 分割点数 + 1，各段可独立播放
- [ ] `concat_videos` 同参数片段快速拼接（Demuxer），输出连续
- [ ] `concat_videos` 异参数片段返回明确错误（不静默转码）
- [ ] `extract_thumbnail` 输出图片存在、尺寸合理
- [ ] `ms_to_ffmpeg_time` 覆盖边界值（0, 大数, 带毫秒）

## spec-34 进度解析

- [ ] `FfmpegProgressParser::parse_line` 正确解析 `time=` 和 `speed=`
- [ ] `run_ffmpeg_with_progress` 流式读取 stderr 并调用 callback
- [ ] 裁剪 5s 视频时 on_progress 被调用多次，pct 单调递增
- [ ] `on_progress=None` 时命令函数行为与 spec-33 一致（回归）
- [ ] `FfmpegProgressTick` 事件在 Tauri 前端可接收
- [ ] `useFFmpegProgress` hook 返回最新进度
- [ ] 进度更新频率合理（约每秒 1-2 次）

## spec-35 时间轴 UI

- [ ] `extract_thumbnail_strip` 对 5s 视频产出正确数量的缩略图
- [ ] 缩略图缓存在项目 `thumbnails/strips/` 下，二次调用不重复生成
- [ ] 时间轴正确显示缩略图条
- [ ] 缩略图条加载有 loading 态，生成完成后正确渲染
- [ ] 可拖动左右裁剪手柄
- [ ] 手柄有最小间距约束（≥100ms）
- [ ] 整秒吸附 + Shift 取消吸附
- [ ] 排除区域显示半透明蒙版
- [ ] 时间刻度随缩放级别自适应
- [ ] 播放头与视频播放进度同步
- [ ] 点击时间轴跳转播放位置
- [ ] 拖拽播放头 scrub 视频
- [ ] Ctrl/Cmd + 滚轮缩放

## spec-36 片段编排 + 导出

- [ ] migration 013 正常执行
- [ ] 可创建、编辑、删除片段
- [ ] 拖拽排序后 order_index 正确
- [ ] 从时间轴添加带裁剪范围的片段
- [ ] 导出执行 trim → concat，输出可播放 mp4
- [ ] 导出过程显示进度条
- [ ] 导出完成可打开文件目录

## 端到端演示（必须）

1. [ ] 打开项目，检查 FFmpeg 状态（绿色可用）
2. [ ] 选择一个已生成的视频素材，probe 显示元数据（时长、分辨率、编解码器）
3. [ ] 进入视频编辑器（EpisodeDetailPage → 视频编辑按钮）
4. [ ] 时间轴加载缩略图条（有 loading → 显示缩略图）
5. [ ] 拖动裁剪手柄截取 2s–8s 片段
6. [ ] 「添加到片段列表」→ 片段列表出现一条记录
7. [ ] 再添加 2 个片段（共 3 个），拖拽调整顺序
8. [ ] 点击「导出」→ 选择分辨率 → 确认
9. [ ] 进度条从 0% 增长到 100%
10. [ ] 播放导出视频，画面连续无卡顿，顺序与片段列表一致
