# MS3 节点画布 · 手动验证清单

本文档汇总 spec-20 ~ spec-24 的全部"手动验证"项，供 MS3 收尾时在真实 GUI 上逐项过一遍。

**前置准备**

```bash
pnpm tauri dev
```

打开任意一个项目；DB 直查命令默认走 SQLite CLI：

```bash
sqlite3 "$(查 reference_data_locations.md 里给出的路径)/mango.db"
```

---

## spec-20 · Episode + Shot CRUD（数据基础）

入口：左侧导航 **「剧本」** tab（位于「主体库」之后）

- [ ] 进项目 → 点击「剧本」tab → 看到 `EpisodeListPage` 空态
- [ ] 新建一集「第一幕：开学」→ 看到 `EpisodeCard`
- [ ] 点进 `EpisodeDetailPage` → 编辑 `script_text` 失焦 → 重启应用 → 文本保留
- [ ] 在 `EpisodeDetailPage` 下方 `ShotListPanel` 建 3 个分镜 → 可拖动排序
- [ ] 删一集 → 该集的 shot 全部消失（DB 验证 `SELECT * FROM shot WHERE episode_id = '...'` 返回空）

---

## spec-21 · 画布骨架 + 自动持久化

入口：`EpisodeDetailPage` 右上角 **「跳画布」** 按钮

- [ ] 进入一集 → 点「跳画布」→ 看到空画布 + minimap + controls + grid
- [ ] 在画布上双击空白处（不会创建节点，但不应报错）
- [ ] 滚轮缩放 / 拖动平移正常
- [ ] DevTools 调 `upsert_canvas_layout` 注入一个节点 → 刷新页面 → 节点恢复
- [ ] DB 直查 `SELECT * FROM canvas_layout WHERE episode_id = '...'` 验证字段写入
- [ ] 反复拖动节点 → DB `updated_at` 1s 一次而非每帧（自动保存 1s 防抖 + 哈希去重）
- [ ] 关闭画布重开 → 缩放/平移位置恢复（viewport 持久化）

## spec-22 · 5 种业务节点 + 连线

入口：画布空白处 **右键** → PaneContextMenu

- [ ] 右键 → 看到 5 个「添加节点」菜单项
- [ ] 添加 `ScriptNode` → 看到 episode.script_text 前 3 行
- [ ] 双击 `ScriptNode` → 展开看到全文 → 刷新 → 仍保持展开
- [ ] 同一 episode 第二次「新建剧本节点」→ toast「该节点已在画布上」
- [ ] 添加 `StoryboardNode`（选 status=draft 的 shot）→ 灰色边框
- [ ] 在 `EpisodeDetailPage` 改 shot status 为 ready → 回画布 → 边框变蓝
- [ ] 添加 `CharacterNode` + `StoryboardNode` → 拖连线 → 实线 + 角色图标 → DB `shot_character` 新增一行
- [ ] 选中该 edge → 按 Delete → DB `shot_character` 对应行消失（**edge-only 删除**）
- [ ] 再连一次 → 删 `CharacterNode` → DB `shot_character` 行消失（**节点删除路径**）
- [ ] 添加 `TaskNode`（选 running 任务）→ 黄色边框 → 任务完成 → 边框变绿
- [ ] 添加 `AssetNode`（选 video）→ 看到「播放」按钮 → 点击弹 ResultPreviewDialog
- [ ] 项目无任何分镜时打开 ShotPickerDialog → 空态 + 跳 `EpisodeDetailPage` 按钮

## spec-23 · 拖放（内部 + 外部）

入口：画布右上角 **FolderOpen** 图标 → AssetDrawer

- [ ] 点 FolderOpen → AssetDrawer 滑出 + 显示项目素材
- [ ] AssetDrawer 拖一张图片到画布空白 → 创建 `AssetNode`（drawer 不自动关闭）
- [ ] 拖 image asset 到 `StoryboardNode` → 弹「确认绑定」（无警告）→ 确认 → DB `asset.shot_id` 更新；toast「已设为分镜的参考素材」
- [ ] 同一 asset 拖到**另一个** `StoryboardNode` → 弹「覆盖并绑定」（**黄色警告显示当前绑定 shot 名**）→ 覆盖 → DB shot_id 更新
- [ ] 拖 video asset 到 `StoryboardNode` → 确认 → toast「已采用为分镜的视频结果」
- [ ] 从 Finder 拖一张 .png 到画布 → import 完成 + `AssetNode` 出现在鼠标松开位置（**Retina 屏验证无 2x 偏移**）
- [ ] 从 Finder 拖一个 .txt → toast 错误，不创建节点
- [ ] 从 Finder 拖混合（2 png + 1 txt）→ toast warning「已忽略 1 个」+ 2 个 AssetNode 错位排列
- [ ] 同一文件拖入两次 → DB 只多 1 行 asset，画布只有 1 个 AssetNode + toast「该素材已在画布上」
- [ ] AssetDrawer 收起后，画布右上区域可正常右键弹 PaneContextMenu
- [ ] 角色编辑对话框的 `ReferenceImageDropzone` 仍能接收系统拖入（`useGlobalDropTarget` 栈语义未破）
- [ ] ⚠️ **遗留 bug #2**：「素材库拖到画布没东西」——上次未回诊断信息，本轮重点复测

## spec-24 · Undo/Redo + 工具栏 + 版本占位

入口：画布顶部 **CanvasToolbar**（撤销/重做/缩放/适应视图/保存版本）

- [ ] 右键创建 `StoryboardNode` → Cmd+Z → 节点消失
- [ ] Cmd+Shift+Z → 节点重现
- [ ] **首次打开**有已存 layout 的 episode → Cmd+Z → 画布不变（验证 `init` pause/resume）
- [ ] 拖动节点 100 像素 → 松手 → Cmd+Z → 回到拖动**前**位置（不是回退一像素）
- [ ] 拖画布平移 → Cmd+Z → 节点不变（viewport 不在栈）
- [ ] 在 `ScriptNode` textarea 内输入 → Cmd+Z → 撤销的是 textarea 文字（不是画布）
- [ ] 工具栏 +/− → ZoomIndicator 百分比实时更新；10%↔100% **数字不抖动**
- [ ] 「适应视图」→ 画布 zoom 到容纳全部节点
- [ ] 「保存版本」→ toast「已保存版本」→ DB `episode_checkpoint` 新行（`trigger_type='manual'`、`canvas_nodes_json` 含完整 JSON）
- [ ] 连续两次「保存版本」→ `version_number` 1 → 2
- [ ] 连按 Cmd+Z 60 次 → **第 51 次起 undo 按钮 disabled**（栈深度 50）
- [ ] Cmd+Z 撤销「char → shot 连线」→ 画布上边消失，但 DB `shot_character` 行**仍在**（业务副作用不回滚是设计决议）
- [ ] **macOS 上按 Cmd+Y** → 不触发 redo（系统行为接管，不报错）
