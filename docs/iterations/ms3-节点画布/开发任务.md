# MS3: 节点画布

## 迭代目标

实现核心差异化功能——漫剧业务语义的节点画布，用户能在画布上可视化编排剧情和素材。

**预估工时**：40-60 小时（~4 周）

**前置依赖**：MS2（需要已有的素材和生成任务数据）

---

## 任务清单

### 任务 1：React Flow 集成 + 基础画布

**任务描述**：集成 React Flow 12，配置基础画布交互。

**开发概设**：
- 安装 `@xyflow/react` v12
- 画布基础配置：缩放/平移/minimap/controls
- 画布容器组件：`features/canvas/Canvas.tsx`
- 集成到项目工作区页面，按 episode 加载画布

**验收标准**：
- [ ] 画布可正常渲染、缩放、平移
- [ ] Minimap 和 Controls 组件显示正常
- [ ] 画布占据主内容区完整空间

---

### 任务 2：ScriptNode（剧本节点）

**任务描述**：实现剧本节点，显示剧本文本并支持展开编辑。

**开发概设**：
- 自定义节点组件：`nodes/ScriptNode.tsx`
- 显示：剧本标题 + 文本摘要（折叠状态 3 行）
- 交互：双击展开编辑，支持多行文本编辑
- 数据：关联 Episode.script_text

**验收标准**：
- [ ] 节点显示剧本文本摘要
- [ ] 双击可展开编辑
- [ ] 编辑后内容保存到数据库
- [ ] 节点大小自适应内容

---

### 任务 3：StoryboardNode（分镜节点）

**任务描述**：实现分镜节点，显示分镜信息和状态。

**开发概设**：
- 显示：分镜序号 + 摘要 + 缩略图（如有）+ 状态标记
- 状态颜色标记：draft(灰)/ready(蓝)/generating(黄)/done(绿)
- 可展开显示详细信息：镜头类型、情绪、对白

**验收标准**：
- [ ] 节点正确显示分镜信息
- [ ] 状态标记颜色正确
- [ ] 有缩略图时正确展示
- [ ] 可展开查看详细信息

---

### 任务 4：CharacterNode（角色节点）

**任务描述**：实现角色节点，显示角色信息和参考图。

**开发概设**：
- 显示：角色名 + 参考图缩略图
- 连线：可连接到 StoryboardNode（表示角色出场）
- 点击可查看角色详情

**验收标准**：
- [ ] 节点正确显示角色名和缩略图
- [ ] 无参考图时显示占位符
- [ ] 可与分镜节点连线

---

### 任务 5：TaskNode（任务节点）

**任务描述**：实现生成任务节点，显示任务状态和结果预览。

**开发概设**：
- 显示：任务类型图标 + 状态 + 结果缩略图（成功时）
- 实时状态更新：监听 Tauri event
- 连线：从 StoryboardNode → TaskNode（分镜的生成任务）

**验收标准**：
- [ ] 节点状态实时更新
- [ ] 成功时显示结果缩略图
- [ ] 失败时显示错误标记

---

### 任务 6：AssetNode（素材节点）

**任务描述**：实现素材节点，显示图片/视频缩略图和文件信息。

**开发概设**：
- 显示：缩略图 + 文件名 + 文件类型图标 + 尺寸/时长
- 视频：只显示缩略图 + 时长，点击弹窗播放
- 连线：TaskNode → AssetNode（任务的输出）

**验收标准**：
- [ ] 图片素材显示缩略图
- [ ] 视频素材显示缩略图 + 时长
- [ ] 点击视频素材可弹窗播放

---

### 任务 7：自定义 Edge 样式

**任务描述**：实现业务关系连线的自定义样式。

**开发概设**：
- 不同关系类型不同连线样式：
  - 角色→分镜：实线，带角色图标
  - 分镜→任务：虚线
  - 任务→素材：点线
- 连线上可显示标签
- 支持删除连线（右键菜单或选中后 Delete）

**验收标准**：
- [ ] 不同关系类型视觉上可区分
- [ ] 连线平滑不交叉（使用 smoothstep 或 bezier）
- [ ] 可删除已有连线

---

### 任务 8：素材面板 → 画布拖放

**任务描述**：实现从素材面板拖放素材到画布上创建节点。

**开发概设**：
- HTML5 Drag & Drop API
- 素材面板中拖动时 dataTransfer 携带 asset_id
- 画布 onDrop：根据 asset_id 创建 AssetNode 并定位到放置位置
- 拖放到分镜节点上：绑定为该分镜的参考图/采用视频

**验收标准**：
- [ ] 从素材面板拖入画布空白区域创建 AssetNode
- [ ] 拖入到分镜节点上触发绑定操作
- [ ] 拖动过程中有视觉反馈（拖影/高亮）

---

### 任务 9：系统文件 → 画布拖放

**任务描述**：支持从系统文件管理器直接拖入文件到画布。

**开发概设**：
- 通过 Tauri `onDragDropEvent` 拦截系统拖放
- 自动执行 import_asset（校验 → 复制 → 缩略图 → 入库）
- 导入成功后在放置位置创建 AssetNode

**验收标准**：
- [ ] 从 Finder/Explorer 拖入图片/视频文件成功导入
- [ ] 导入后自动在画布上创建节点
- [ ] 不支持的文件格式给出提示

---

### 任务 10：CanvasLayout 持久化

**任务描述**：实现画布布局的自动持久化，含大画布性能优化。

**开发概设**：
- 将 React Flow 的 nodes/edges/viewport 序列化为 JSON
- 存入 CanvasLayout 表（episode_id 关联）
- 防抖 1 秒自动保存
- 打开项目/切换集时从 DB 恢复画布状态
- 增量保存：记录上次快照哈希，未变更时跳过写入
- 大画布优化（节点 > 50）：使用 Web Worker 执行 JSON 序列化，避免阻塞主线程

**验收标准**：
- [ ] 关闭重开应用后画布状态完整恢复
- [ ] 节点位置、连线关系、缩放状态均正确恢复
- [ ] 防抖机制工作正常（快速操作不会频繁写库）
- [ ] 无变更时不触发写入（通过哈希对比）
- [ ] 50+ 节点时序列化不阻塞 UI 交互

---

### 任务 11：Undo/Redo

**任务描述**：实现画布操作的撤销/重做。

**开发概设**：
- 使用 Zustand + zundo (temporal middleware)
- 栈深度限制 50 步
- 覆盖操作：节点移动、创建、删除、连线变更
- 快捷键：Ctrl+Z / Ctrl+Y (macOS: Cmd+Z / Cmd+Shift+Z)

**验收标准**：
- [ ] Ctrl+Z 撤销最近操作
- [ ] Ctrl+Y 重做已撤销操作
- [ ] 栈满后最早的操作被丢弃
- [ ] 应用关闭后 undo 栈清空（预期行为）

---

### 任务 12：画布工具栏

**任务描述**：实现画布顶部工具栏。

**开发概设**：
- 工具按钮：缩放(+/-)、适应视图、撤销、重做、保存版本
- 缩放指示器：显示当前缩放百分比
- 保存版本：手动创建 EpisodeCheckpoint

**验收标准**：
- [ ] 所有工具按钮功能正常
- [ ] 适应视图将所有节点纳入可视范围
- [ ] 保存版本创建检查点并给出反馈
