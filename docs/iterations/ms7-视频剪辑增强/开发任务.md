# MS7: 视频剪辑增强

## 迭代目标

补齐漫剧成片所需的视觉编辑能力：多轨时间轴、镜头动态化（Ken Burns / 关键帧）、转场、文字系统（字幕/气泡/花字/拟声词）、贴片装饰、视觉特效。使用户在 Mango 内完成从 AI 生图到可发布漫剧视频的全部剪辑工作，无需导出到第三方工具。

**预估工时**：120–160 小时（~8–12 周，拆 8 个任务 / 首批 4 个 spec）

**前置依赖**：MS5（FFmpeg 基础命令 + 单轨时间轴）、MS6（配音/音效/字幕烧录 + 成片合成）

## 关键设计修正（相对原始任务书）

1. **filter_graph.rs 已存在** — 「扩展现有」而非「新建」（184 行，6 个音频 filter，被 audio.rs 依赖）
2. **删除 FilterChain 抽象** — 扁平 `Vec<FilterNode>` 模型足够，不增加不必要的层
3. **新增 normalize 方法** — xfade/concat 要求同分辨率/帧率/像素格式，现有 `check_concat_compatibility` 仅检查 Copy 模式
4. **probe.rs 扩展 pixel_format** — VideoMetadata 新增字段，供 normalize 判断
5. **保留现有导出函数** — `export_resolved_clips` / `export_final` 不动，新建 `export_timeline` 读 timeline_* 表
6. **替代 Timeline + ClipAssembly 两者** — 多轨时间轴统一 clip 列表和裁剪时间轴
7. **TimelineControls 需重写** — trimStart/trimEnd 接口不适用多轨
8. **补齐三个缺失设计** — FFmpeg 代理预览、MS6 音频导入机制（`import_audio_from_shots`）、`TimelineItemParams` typed enum

## 任务 4-8 spec 设计决策（2026-06-16）

第一批 spec（42-46）已全部实现，任务 4-8 已完成 spec 拆分（47-52）。关键对齐决策：

**已确认的 API 表面**：
- `FilterGraph`：zoompan/xfade/drawtext/overlay/scale/pad/crop/colorbalance/eq 等 12 个视频 filter 方法可用
- `RenderConfig`：支持 codec/preset/crf/output_width/output_height/output_fps，待 spec-52 新增 fit_mode
- `TimelineItemParams`：5 个 variant（Clip/Text/Transition/Sticker/Effect）已定义，spec-50 将结构化 Text.style
- `timeline_keyframe` 表 + CRUD 已就绪，spec-48 直接使用

**设计取舍**：
- 任务 4（关键帧）：首版只做 Ken Burns 预设（8 个 zoompan 模板），不做通用关键帧编辑器 UI。rotation/opacity 动画延后
- 任务 5（转场）：仅 xfade 视频转场，不做 acrossfade 音频交叉淡化
- 任务 6（文字系统）：保留为单一 spec-50（不再拆分），首版用 FFmpeg drawtext 渲染字幕/花字/拟声词，气泡用 drawtext+drawbox 简化方案（不引入 resvg）
- 任务 7（贴片+特效）：首版仅静态 PNG 贴纸 + 调色预设，动画贴纸/粒子/镜头效果延后
- 任务 8（导出增强）：封面帧仅手动选取，不做自动推荐。批量导出延后
- 新增 spec-47：补齐编辑器基础体验（删除/Undo 快捷键/音频预览/裁剪手柄/分割/吸附/跨轨道拖拽），作为第二批的前置
