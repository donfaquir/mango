# MS7: 视频剪辑增强

## 迭代目标

补齐漫剧成片所需的视觉编辑能力：多轨时间轴、镜头动态化（Ken Burns / 关键帧）、转场、文字系统（字幕/气泡/花字/拟声词）、贴片装饰、视觉特效。使用户在 Mango 内完成从 AI 生图到可发布漫剧视频的全部剪辑工作，无需导出到第三方工具。

**预估工时**：80–110 小时（~6–8 周，拆 8 个任务）

**前置依赖**：MS5（FFmpeg 基础命令 + 单轨时间轴）、MS6（配音/音效/字幕烧录 + 成片合成）

## 任务清单

### 任务 1：FFmpeg filter graph builder

**任务描述**：构建 FFmpeg `-filter_complex` 命令生成器，为所有视觉效果提供后端基础。

**开发概设**：
- 新建 `crates/core/src/ffmpeg/filter_graph.rs`，定义 filter graph DSL：
  - `FilterGraph` 结构体：管理输入流、filter 节点、输出流
  - `FilterNode`：表示单个 filter（如 `zoompan`, `xfade`, `drawtext`, `overlay`, `colorbalance`）
  - `FilterChain`：有序 filter 链，处理单一流
  - `build()` 方法：生成 `-filter_complex` 字符串 + 对应的 `-map` 参数
- 内置常用 filter 的类型安全构造器：
  - `zoompan`（Ken Burns）
  - `xfade`（转场）
  - `drawtext`（文字叠加）
  - `overlay`（贴片/水印）
  - `colorbalance` / `eq` / `lut3d`（调色）
  - `scale` / `pad`（宽高比变换）
- 新建 `crates/core/src/ffmpeg/render.rs`，封装完整的渲染函数：
  - `render_timeline(config, timeline_data, output_path, on_progress)` — 从时间轴数据生成 filter graph → 执行 FFmpeg → 输出文件
  - 渲染流程：解析时间轴数据 → 为每个 clip 生成 filter chain → 组合转场 → 叠加文字/贴片 → 混合音频 → 输出
- 进度计算复用 `progress.rs` 的 `FfmpegProgressParser`

**验收标准**：
- [ ] `FilterGraph::build()` 对 3 个输入 + zoompan + xfade 生成正确的 `-filter_complex` 字符串
- [ ] 生成的命令可被 FFmpeg 正确执行（集成测试用真实 FFmpeg）
- [ ] 单元测试覆盖各 filter 构造器的参数序列化
- [ ] 复杂 graph（5+ 输入、混合 filter）生成的命令无语法错误

### 任务 2：重编码导出管线

**任务描述**：将当前 `-c copy` 拼接模式升级为支持 filter graph 的重编码管线，使转场、特效、文字叠加等功能成为可能。

**开发概设**：
- 扩展 `export.rs` 的 `export_resolved_clips()`，新增 `ExportMode` 枚举：
  - `Copy`：当前行为，无 filter、快速拼接（无转场/特效时自动选用）
  - `Render`：通过 filter graph 重编码输出（有转场/特效/文字时自动选用）
- `Render` 模式下的编码参数：
  - 视频：libx264 / libx265（根据用户选择），preset 可配置（ultrafast → slow），CRF 可配置
  - 音频：aac 128k（透传 MS6 的音频混合结果）
  - 容器：mp4（默认）、webm（可选）
- 智能选择策略：如果时间轴数据中所有 clip 无 filter/无转场/同参数 → 自动降级为 Copy 模式
- Tauri IPC 扩展：`export_timeline` 命令（接收完整时间轴数据 JSON），替代简单的 `export_video_clips`
- CLI 扩展：`mango export timeline --episode <id> --output <path> [--preset fast] [--crf 18]`

**验收标准**：
- [ ] 无特效时间轴自动使用 Copy 模式，速度与 MS5 一致
- [ ] 有特效时间轴使用 Render 模式，输出正确合成的视频
- [ ] CRF / preset 参数可配置且生效
- [ ] 进度条在 Render 模式下正常工作
- [ ] 输出文件可在主流播放器播放

### 任务 3：多轨时间轴数据模型 + UI

**任务描述**：将单轨时间轴升级为多轨 NLE 时间轴，支持视频轨、文字轨、贴片轨、音频轨的叠加显示和编辑。

**开发概设**：

**数据模型**（DB migration）：
- `timeline_track` 表：`id, episode_id, track_type (video|audio|text|overlay), label, order_index, muted, locked`
- `timeline_item` 表：`id, track_id, asset_id (nullable), item_type (clip|text|sticker|transition|effect), position_ms, duration_ms, in_point_ms, out_point_ms, params_json, order_index`
  - `params_json`：存储类型特定参数（Ken Burns 预设、转场类型、文字内容/样式、贴片资源路径等）
  - `position_ms`：item 在轨道上的绝对起始位置
  - `in_point_ms` / `out_point_ms`：源素材的裁剪入出点
- `timeline_keyframe` 表：`id, item_id, property (position_x|position_y|scale|rotation|opacity), time_ms, value, easing (linear|ease_in|ease_out|ease_in_out)`
- 保留 `video_clip` 表兼容性 — MS5/MS6 的简单导出仍可用；多轨导出读 `timeline_*` 表

**前端状态**（Zustand store 重构）：
- 新建 `src/stores/multiTrackStore.ts`，替代 `timelineStore.ts`：
  - `tracks: Track[]`（有序轨道列表）
  - `items: Map<string, TimelineItem>`（按 ID 索引的 item 集合）
  - `selection: Set<string>`（当前选中的 item IDs）
  - `playhead: number`（播放头位置 ms）
  - `zoom: number`、`scrollX: number`（视口控制）
  - CRUD actions：`addTrack`, `removeTrack`, `addItem`, `moveItem`, `resizeItem`, `deleteItem`
  - undo/redo 集成（`zundo` middleware，复用画布的模式）
- 持久化：通过 Tauri IPC 保存到 DB，auto-save with 1s debounce（复用画布的 auto-save 模式）

**UI 组件**：
- `MultiTrackTimeline.tsx`：替代当前 `Timeline.tsx`
  - 左侧轨道标签面板（轨道名称、静音/锁定按钮、轨道类型图标）
  - 右侧可滚动的时间轴区域
  - 每条轨道一行，item 显示为带颜色的方块
  - 轨道之间可拖拽 item
- `TimelineItem.tsx`：单个 item 的可视化（clip 显示缩略图、text 显示文字预览、transition 显示图标）
- `TrackHeader.tsx`：轨道标签区域
- 保留并复用：`TimeScale.tsx`、`PlaybackHead.tsx`、`TimelineControls.tsx`

**默认轨道结构**：新建时间轴时自动创建：
1. 视频轨（主视频）
2. 贴片/特效轨
3. 文字轨
4. 配音轨（来自 MS6）
5. BGM 轨（来自 MS6）
6. 音效轨（来自 MS6）

**验收标准**：
- [ ] 可创建、删除、重排轨道
- [ ] 可在轨道上添加、移动、调整大小、删除 item
- [ ] item 可跨轨道拖拽
- [ ] 播放头同步视频预览
- [ ] Undo/Redo 对所有操作生效
- [ ] 时间轴数据自动保存到 DB
- [ ] 6 条默认轨道正确创建

### 任务 4：关键帧动画系统 + Ken Burns 预设

**任务描述**：实现关键帧动画系统，支持对 item 的位置/缩放/旋转/透明度做时间插值动画。并提供 Ken Burns 动态预设，一键应用镜头运动。

**开发概设**：

**关键帧系统**：
- 后端：`timeline_keyframe` 表（见任务 3），CRUD 查询
- 前端：`useKeyframes.ts` hook，`KeyframeEditor.tsx` 组件
  - 在 item 详情面板中显示关键帧时间线
  - 可添加/删除/拖动关键帧节点
  - 支持 4 种缓动曲线：`linear`, `ease_in`, `ease_out`, `ease_in_out`
  - 可动画化的属性：`position_x`, `position_y`, `scale`, `rotation`, `opacity`
- FFmpeg 映射：关键帧数据 → `zoompan` filter 参数（position/zoom 随时间变化）
  - `zoompan=z='if(between(in_time,0,3),1+0.001*in_time*25,1.075)':x='...':y='...'`
  - 复杂情况：多段 keyframe → 拼接多个 zoompan 表达式

**Ken Burns 预设**：
- 内置 8 个常用预设（存储为预定义 keyframe 序列）：

| 预设名 | 效果 | 参数 |
|---|---|---|
| 缓慢推进 | 从全景缓慢放大到中心 | scale: 1.0 → 1.15, 4s |
| 缓慢拉远 | 从中心放大状态缓慢缩小 | scale: 1.15 → 1.0, 4s |
| 左移 | 画面从右向左平移 | x: 0% → -10%, 4s |
| 右移 | 画面从左向右平移 | x: -10% → 0%, 4s |
| 上移 | 画面从下向上平移 | y: 0% → -10%, 4s |
| 下移 | 画面从上向下平移 | y: -10% → 0%, 4s |
| 推进+右移 | 组合：放大+平移 | scale+x 组合 |
| 戏剧推进 | 快速推进到特定区域 | scale: 1.0 → 1.4, ease_in, 2s |

- 用户选择预设后自动创建对应的 keyframe 序列，之后可手动微调
- 批量应用：选中多个 clip → 一键套用相同预设

**其他镜头特效**（基于 filter）：
- 镜头抖动：`crop` filter + 随机偏移表达式
- 闪白/闪黑：在两个 clip 之间插入纯色帧 + fade
- 定格：复制最后一帧 → 延长为指定时长的静态片段

**验收标准**：
- [ ] 可为 clip 添加/编辑/删除关键帧
- [ ] 关键帧时间线可视化正确
- [ ] 4 种缓动曲线在导出视频中效果正确
- [ ] 8 个 Ken Burns 预设一键应用，导出视频动效符合预期
- [ ] 预设应用后可手动修改关键帧
- [ ] 批量应用预设到多个 clip
- [ ] 镜头抖动效果在导出中正确渲染

### 任务 5：转场库

**任务描述**：实现视频片段之间的转场效果，提供漫剧常用的转场类型。

**开发概设**：
- 转场在数据模型中表示为 `timeline_item`，`item_type = 'transition'`，`params_json` 存储转场类型和参数
- 转场放置在两个相邻 clip 之间，UI 上显示为连接两个 clip 的图标
- 转场时长可拖拽调整（默认 500ms，范围 100ms–2000ms）
- FFmpeg 实现基于 `xfade` filter（视频）+ `acrossfade` filter（音频）

**转场类型**（首批 8 种）：

| 类型 | FFmpeg xfade transition | 风格 |
|---|---|---|
| 叠化 | `dissolve` | 通用 |
| 淡入黑场 | `fade` + 黑色中间帧 | 通用 |
| 淡入白场 | `fade` + 白色中间帧 | 通用 |
| 左擦除 | `wipeleft` | 通用 |
| 右擦除 | `wiperight` | 通用 |
| 圆形展开 | `circleopen` | 漫画风 |
| 圆形收缩 | `circleclose` | 漫画风 |
| 像素化 | `pixelize` | 风格化 |

- 转场预览：在时间轴上 hover 转场图标时显示缩略图预览（取两个 clip 的边界帧合成）
- 添加转场：在两个相邻 clip 之间点击 `+` 按钮，弹出转场选择器

**验收标准**：
- [ ] 可在两个相邻 clip 之间添加转场
- [ ] 8 种转场类型在导出视频中效果正确
- [ ] 转场时长可调整
- [ ] 转场可删除/替换
- [ ] 无转场时片段之间为硬切（不影响现有行为）
- [ ] 音频跨转场正确交叉淡化

### 任务 6：文字系统

**任务描述**：实现完整的文字系统，包括样式化字幕、漫画气泡、花字标题、拟声词，支持模板和动画。

**开发概设**：

**数据模型**：文字作为 `timeline_item`（`item_type = 'text'`）放在文字轨上，`params_json` 存储：
```json
{
  "text_type": "subtitle|bubble|fancy|onomatopoeia",
  "content": "震惊！",
  "style": {
    "font_family": "Noto Sans SC",
    "font_size": 48,
    "font_weight": "bold",
    "color": "#FFFFFF",
    "outline_color": "#000000",
    "outline_width": 2,
    "shadow": true,
    "background": { "type": "none|solid|gradient|image", "value": "..." },
    "position": { "x": 0.5, "y": 0.9 },
    "alignment": "center",
    "vertical": false
  },
  "bubble": {
    "shape": "oval|rect|cloud|shout|whisper",
    "tail_direction": "bottom_left",
    "fill_color": "#FFFFFF",
    "border_color": "#000000"
  },
  "animation": {
    "enter": "none|fade_in|pop_in|typewriter|slide_up",
    "exit": "none|fade_out|pop_out|slide_down",
    "enter_duration_ms": 300,
    "exit_duration_ms": 300
  },
  "template_id": "fancy_shock_01"
}
```

**四种文字类型**：

1. **字幕**（subtitle）：
   - 位于画面底部，支持角色分色（按角色 ID 自动着色）
   - 字幕动画：淡入/逐字出现/弹入
   - 可从 MS6 的 ASS/SRT 数据自动导入，但允许在时间轴上手动编辑

2. **漫画气泡**（bubble）：
   - 5 种气泡形状：圆形对话泡、圆角矩形、云形思考泡、尖角喊叫泡、虚线耳语泡
   - 气泡尾巴方向可调（8 个方位）
   - 气泡内文字自动排版（自动换行、居中）
   - FFmpeg 实现：预渲染气泡为 PNG → `overlay` filter 叠加
   - 气泡 PNG 渲染：后端使用 `resvg`（已有 SVG 能力）或前端 Canvas 预渲染

3. **花字**（fancy text）：
   - 带装饰性背景的大字标题（如「震惊！」「三年后...」「VS」）
   - **模板库**：内置 15-20 个花字模板，按风格分类（热血、搞笑、恐怖、浪漫、悬疑）
   - 每个模板定义：字体、字号、颜色方案、描边、阴影、背景装饰、入场/出场动画
   - 用户选择模板 → 输入文字 → 自动生成；可微调参数

4. **拟声词**（onomatopoeia）：
   - 漫画特有的视觉音效文字：「砰！」「嗖！」「咔嚓！」
   - 特点：大字号、倾斜、手绘/毛笔风格字体、通常带描边和阴影
   - 位置自由放置（不限于底部），可旋转
   - 内置 10+ 常用拟声词模板

**文字编辑 UI**：
- `TextEditorPanel.tsx`：选中文字 item 后在右侧显示编辑面板
  - 文字类型选择
  - 内容输入（富文本）
  - 样式控制（字体/字号/颜色/描边/阴影）
  - 气泡设置（仅 bubble 类型）
  - 动画设置
  - 模板选择器
- `TextTemplateGallery.tsx`：花字/拟声词模板网格，预览 + 一键应用

**FFmpeg 渲染**：
- 字幕：`drawtext` filter（简单文字）或 ASS filter（复杂样式）
- 气泡/花字/拟声词：预渲染为透明 PNG → `overlay` filter 叠加
  - 预渲染时机：导出前，在 core 层完成
  - 动画：通过 `overlay` 的 `enable` 参数 + `fade` filter 实现 enter/exit

**验收标准**：
- [ ] 可在文字轨添加 4 种文字类型
- [ ] 字幕支持角色分色和 3 种入场动画
- [ ] 5 种气泡形状正确渲染，尾巴方向可调
- [ ] 花字模板库可浏览和应用
- [ ] 拟声词可自由定位和旋转
- [ ] 文字编辑面板实时预览样式
- [ ] 导出视频中所有文字类型正确叠加
- [ ] 可从 MS6 的字幕数据一键导入到文字轨

### 任务 7：贴片/装饰元素 + 视觉特效

**任务描述**：实现贴片（表情/特效贴纸、边框装饰）和视觉特效（调色、粒子、镜头效果）。

**开发概设**：

#### 7a. 贴片/装饰

贴片作为 `timeline_item`（`item_type = 'sticker'`）放在贴片轨上。

- **表情贴纸**：漫画常用视觉符号（汗滴、怒筋、问号、爱心、星星眼、省略号）
  - 内置 20+ 静态贴纸（SVG/PNG）
  - 带简单动画（弹出、浮动、抖动）
  - 用户可导入自定义图片作为贴纸

- **特效贴纸**：火焰、闪电、冲击线、速度线、光效、花瓣飘落
  - 内置 10+ 动态特效（序列帧或参数化动画）
  - 可调参数：强度、方向、颜色

- **边框装饰**：
  - 漫画格边框叠加（黑色粗线框、圆角框、不规则手绘框）
  - 分屏模板（2 格、3 格、4 格布局）
  - 位置和大小可调

- FFmpeg 实现：所有贴片预渲染为带透明通道的 PNG 序列 → `overlay` filter 叠加

#### 7b. 视觉特效

- **调色/滤镜**：
  - 内置 10 个情绪预设：暖调、冷调、怀旧、黑白、高对比、低饱和、夜景、黄昏、梦幻、恐怖
  - FFmpeg 实现：`colorbalance`, `eq`, `hue` filter 组合
  - 调色应用到整个 clip 或指定时间段

- **粒子特效**：
  - 6 种常用粒子：雪花、樱花、雨滴、尘埃、火星、光斑
  - 参数：密度、速度、方向、颜色
  - FFmpeg 实现：预渲染粒子序列（透明 PNG/WebM）→ `overlay` filter 循环叠加

- **镜头效果**：
  - 暗角（`vignette` filter）
  - 漏光/光晕（预渲染素材 overlay）
  - 色差（`rgbashift` filter）
  - 背景虚化（`boxblur` / `gblur` filter + mask）

- 特效优先级：调色 > 粒子 > 镜头效果。粒子和镜头效果为可选增强项。

**验收标准**：
- [ ] 可在贴片轨添加表情贴纸并调整位置/大小/时间
- [ ] 可导入自定义图片作为贴纸
- [ ] 10 个调色预设在导出视频中效果正确
- [ ] 至少 3 种粒子特效可用（雪花、樱花、雨滴）
- [ ] 暗角效果可调节强度
- [ ] 多个特效可叠加（如调色 + 粒子 + 暗角）

### 任务 8：导出增强

**任务描述**：增强导出功能，支持多宽高比、平台预设、封面帧生成。

**开发概设**：
- **宽高比变换**：
  - 预设：9:16（抖音/TikTok）、16:9（B站/YouTube）、1:1（微信/小红书）、3:4（小红书竖版）
  - 变换策略：裁剪（crop to fit）或填充（pad with blur/color）
  - FFmpeg 实现：`scale` + `pad` 或 `crop` filter
  - 支持源视频和目标比例不同时的智能处理

- **平台预设**：
  - 抖音：9:16, 1080×1920, H.264, 8Mbps, 最长 5 分钟
  - B站：16:9, 1920×1080, H.264, 10Mbps
  - 微信视频号：9:16 or 16:9, 1080p, H.264
  - 小红书：3:4 or 1:1, 1080p
  - 自定义：用户指定分辨率/码率/格式

- **封面帧**：
  - 从视频中选取任意帧作为封面
  - 自动推荐：选取画面信息量最大（色彩丰富度/清晰度评分最高）的帧
  - 封面导出为独立图片文件（JPG/PNG）
  - 可在封面上叠加标题文字（复用花字模板）

- **批量导出**：选择多集 → 一键按相同设置导出所有集

**验收标准**：
- [ ] 4 种宽高比预设正确输出
- [ ] 裁剪和填充两种策略可选
- [ ] 平台预设自动配置正确的分辨率/码率
- [ ] 可选取封面帧并导出为图片
- [ ] 批量导出多集，进度逐集显示
- [ ] CLI 支持 `--ratio 9:16 --platform douyin` 参数
