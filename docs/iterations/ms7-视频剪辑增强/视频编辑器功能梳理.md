# 视频编辑器功能梳理

> 基于 `feature/20260612-normal-p-1` 分支源码分析，更新日期：2026-06-16

## 一、整体架构

```
VideoEditorPage (路由入口)
├── Header（标题 + 导出按钮）
├── MultiTrackEditor（编辑器主体）
│   ├── VideoPreview（视频预览窗口）
│   ├── MultiTrackTimeline（多轨时间轴）
│   │   ├── TrackHeader × N（轨道头：图标/标签/静音/锁定/删除）
│   │   ├── TimeScale（时间刻度尺）
│   │   ├── TimelineItemBlock × N（片段块：视频缩略图/音频波形/文本预览）
│   │   └── PlaybackHead（播放头指示线）
│   └── MultiTrackControls（底部控制栏）
└── ExportSettingsSheet（导出设置侧边栏）
```

**路由**：`/project/:projectId/episodes/:episodeId/editor`

**状态管理**：Zustand (`multiTrackStore`) + Zundo (撤销/重做，最多 50 步)

**数据流**：前端 Zustand → Tauri IPC → Rust Core (SQLite) → 返回前端更新 Store

## 二、数据模型

### 轨道 (TimelineTrack)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | UUID |
| episode_id | string | 所属集 |
| track_type | `"video" \| "audio" \| "text" \| "overlay"` | 轨道类型 |
| label | string | 显示名称 |
| order_index | number | 排序序号 |
| muted | boolean | 是否静音 |
| locked | boolean | 是否锁定 |

### 片段 (TimelineItem)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | UUID |
| track_id | string | 所属轨道 |
| asset_id | string \| null | 关联素材（文本类型为 null） |
| item_type | `"clip" \| "text" \| "sticker" \| "transition" \| "effect"` | 片段类型 |
| position_ms | number | 在时间轴上的起始位置（毫秒） |
| duration_ms | number | 持续时长 |
| in_point_ms | number | 素材内的起始裁剪点 |
| out_point_ms | number | 素材内的结束裁剪点 |
| params_json | string | 类型相关参数（如文本内容、样式等） |
| order_index | number | 同轨道内排序 |

### 关键帧 (TimelineKeyframe) — 类型已定义，UI 未实现

| 字段 | 类型 | 说明 |
|------|------|------|
| item_id | string | 所属片段 |
| property | string | 动画属性名 |
| time_ms | number | 关键帧时间点 |
| value | number | 属性值 |
| easing | string | 缓动函数 |

## 三、已实现功能

### 3.1 多轨时间轴

| 功能 | 状态 | 说明 |
|------|------|------|
| 多轨道布局 | ✅ | 视频/音频/文本/叠加层四种轨道类型 |
| 添加轨道 | ✅ | 底部"添加轨道"下拉菜单 |
| 删除轨道 | ✅ | 轨道头上的删除按钮，带确认对话框 |
| 静音/锁定轨道 | ⚠️ | UI 可切换，但**未持久化到后端** |
| 轨道拖拽排序 | ❌ | 后端 `reorderTimelineTracks` 命令已有，前端未实现拖拽 |
| 时间刻度尺 | ✅ | 根据缩放级别自适应刻度间隔（500ms ~ 60s） |
| 缩放控制 | ✅ | 底部滑块 + Ctrl/Cmd + 滚轮，范围 0.1x ~ 20x |
| 播放头 | ✅ | 红色竖线 + 三角标记，点击时间轴跳转 |

### 3.2 片段管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 添加视频/音频片段 | ✅ | 通过素材选择器，自动探测时长 |
| 添加文本片段 | ✅ | 弹窗输入内容和类型（字幕/气泡/花字/拟声词），默认 5 秒 |
| 导入镜头 | ✅ | 从 Shots 批量导入视频和音频片段 |
| 拖拽移动片段 | ✅ | 鼠标拖拽改变 `position_ms`，实时反馈 + 松手持久化 |
| 选中片段 | ✅ | 点击选中，Shift 多选 |
| 删除片段 | ❌ | Store 有 `removeItem` 方法，但 UI 上无删除按钮/快捷键 |
| 拖拽调整时长 | ❌ | 旧版 `TrimHandles` 组件存在但未接入多轨编辑器 |
| 跨轨道拖拽 | ❌ | Store 有 `moveItem` 支持改 `track_id`，UI 未实现竖向拖拽 |
| 分割片段 | ❌ | 未实现 |
| 复制/粘贴/复制片段 | ❌ | 未实现 |
| 吸附对齐 | ❌ | 移动无吸附，旧版有 snap-to-second 但未接入 |

### 3.3 片段可视化

| 功能 | 状态 | 说明 |
|------|------|------|
| 视频缩略图条 | ✅ | FFmpeg 每秒抽帧，水平排列填充片段宽度 |
| 音频波形 | ✅ | FFmpeg showwavespic 生成波形图片 |
| 文本内容预览 | ✅ | 显示类型图标 + 内容文字（截断 20 字） |
| 片段颜色编码 | ✅ | 视频/音频=深灰蓝、文本=绿、转场=橙、贴纸=紫、特效=黄 |

### 3.4 播放预览

| 功能 | 状态 | 说明 |
|------|------|------|
| 视频播放 | ✅ | 源文件直接播放，根据 playhead 位置找到对应视频 clip |
| 播放/暂停控制 | ✅ | 按钮 + Space 快捷键 |
| 跳转到开头/结尾 | ✅ | SkipBack / SkipForward 按钮 |
| 播放到结尾自动停止 | ✅ | RAF 循环检测 `totalDuration` |
| Seek 同步 | ✅ | 暂停时精确跳转，播放时偏差 >300ms 才校正 |
| Clip 切换 | ✅ | asset 变化时自动切换 `<video>` src |
| **音频播放** | ❌ | **无 `<audio>` 元素，音频轨道片段不发声** |
| **文本叠加渲染** | ❌ | **预览窗口不显示文本内容** |
| **多视频轨合成** | ❌ | 只播放第一条非静音视频轨 |

### 3.5 导出

| 功能 | 状态 | 说明 |
|------|------|------|
| 导出 MP4 | ✅ | `exportTimeline` 命令，读取 `timeline_track` + `timeline_item` 表 |
| 导出进度条 | ✅ | 监听 `ffmpeg-progress-tick` 事件，显示百分比和速度 |
| 自定义输出路径 | ✅ | 可编辑的文件路径输入框 |
| 自定义编码参数 | ❌ | codec/preset/CRF/分辨率/帧率全部硬编码，UI 不可配置 |

### 3.6 撤销/重做

| 功能 | 状态 | 说明 |
|------|------|------|
| Undo/Redo 机制 | ✅ | Zundo temporal 中间件，仅 tracks 和 items 进入撤销栈 |
| 撤销栈上限 | ✅ | 50 步 |
| 初始化/导入不污染撤销栈 | ✅ | 操作期间 pause → 操作后 resume + clear |
| **Undo/Redo 快捷键** | ❌ | **Ctrl+Z / Ctrl+Y 未绑定** |
| **Undo/Redo 按钮** | ❌ | **UI 上无撤销/重做按钮** |

## 四、后端 IPC 命令清单

| 命令 | 功能 | 调用位置 |
|------|------|---------|
| `listTimelineTracks` | 获取集的所有轨道 | Store init |
| `createDefaultTracks` | 创建默认轨道（video + audio） | Store init（无轨道时） |
| `createTimelineTrack` | 创建新轨道 | addTrack |
| `deleteTimelineTrack` | 删除轨道 | removeTrack |
| `reorderTimelineTracks` | 轨道排序 | toggleMute（占位调用） |
| `listTimelineItems` | 获取轨道的所有片段 | Store init |
| `createTimelineItem` | 创建片段 | addItem |
| `updateTimelineItem` | 更新片段属性 | updateItem |
| `moveTimelineItem` | 移动片段（改位置/轨道） | moveItem |
| `deleteTimelineItem` | 删除片段 | removeItem |
| `importVideoFromClips` | 从镜头导入视频 | importFromShots |
| `importAudioFromShots` | 从镜头导入音频 | importFromShots |
| `exportTimeline` | 导出时间轴为视频 | ExportSettingsSheet |
| `probeVideo` | 探测视频元数据 | 添加视频时获取时长 |
| `probeAudioDuration` | 探测音频时长 | 添加音频时获取时长 |
| `extractThumbnailStrip` | 提取视频缩略图条 | VideoClipThumbnails |
| `extractWaveform` | 提取音频波形图 | AudioClipWaveform |
