# MS1: 主体库 + 账号管理

## 迭代目标

能创建和管理创作所需的角色/场景/道具/服装资产，能配置外部 AI 模型的 API 账号。

**预估工时**：30-45 小时（~3 周）

**前置依赖**：MS0（工程基座）

---

## 任务清单

### 任务 1：Character CRUD

**任务描述**：实现角色实体的完整 CRUD 链路（core + Tauri command + React UI）。

**开发概设**：
- core 层：`db/queries/character.rs` 实现 CRUD
- Character 字段：id, project_id, name, description, appearance_prompt, reference_image_path, created_at
- Tauri command 层：暴露 create/get/list/update/delete 接口
- React UI：角色列表 + 创建/编辑表单

**验收标准**：
- [ ] 可创建角色并填写名称、描述、外貌 prompt
- [ ] 角色列表按项目过滤
- [ ] 可编辑和删除已有角色
- [ ] 单元测试覆盖 core 层 CRUD

### 任务 7：素材导入管线

**任务描述**：实现文件拖入导入功能，将文件复制到项目 assets 目录并生成缩略图。

**开发概设**：
- 拖入文件 → 通过 Tauri `onDragDropEvent` 拦截
- 后端处理：校验文件类型 → 复制到 `assets/{asset_id}.ext` → 生成 webp 缩略图 → Asset 表入库
- 支持图片格式：jpg, png, webp
- 缩略图统一 200x200 webp 格式
- 返回 Asset 记录供前端更新 UI

**验收标准**：
- [ ] 拖入图片文件后自动复制到项目 assets 目录
- [ ] 自动生成缩略图文件
- [ ] Asset 表正确入库（含 content_hash）
- [ ] 不支持的文件格式给出提示

### 任务 8：Provider/Model 预置数据

**验收标准**：

### 任务 9：ApiAccount CRUD + keyring 加密存储

**任务描述**：实现 API 账号管理，密钥通过系统 keyring 安全存储。

**开发概设**：
- ApiAccount 表存储账号元信息，api_key_ref 字段存储 keyring 引用标识
- 实际 API Key 通过 `keyring` crate 存入系统密钥链
- CRUD 操作：创建时存入 keyring，删除时清除 keyring 条目
- 读取时通过 keyring 引用获取实际密钥

**验收标准**：
- [ ] 创建账号时 API Key 存入系统 keyring
- [ ] 列表展示不暴露完整密钥（仅显示后 4 位）
- [ ] 删除账号时 keyring 中对应条目被清除
- [ ] 跨应用重启后密钥仍可正常读取

---

**任务描述**：实现 API 账号的管理界面。

- [ ] API Key 输入框为密码类型

### 任务 11：CLI 主体和账号命令

**任务描述**：实现 CLI 下的角色管理和账号管理命令。

**开发概设**：
- `mango character list` / `mango character create --name "..." --description "..."`

**验收标准**：
- [ ] CLI 创建的角色在 GUI 中可见
