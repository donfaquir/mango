# 项目目标

## 产品定位

> **Mango** —— 本地优先的漫剧创作工作站，从剧本到成片，素材自己管、模型自己选。

### 核心差异化

* **本地优先桌面 App**：数据私有，无需订阅 SaaS，零门槛安装即用

* **漫剧业务语义的节点画布**：非通用节点编辑器，非线性时间轴，而是围绕剧本/分镜/角色/任务的可视化编排

* **多模型聚合 + 账号治理**：不绑定任何单一 Provider，用户自主选择和切换模型

### 目标用户

* 个人 AI 漫剧创作者

* 2-5 人小型内容工作室

***

## 能力目标

### MVP（首版）—— 从剧本到成片跑通

| 序号 | 能力               | 说明                                   |
| -- | ---------------- | ------------------------------------ |
| M1 | 角色/场景/道具资产库（主体库） | 四类实体（角色/场景/道具/服装）管理 + 全局复用，解决角色一致性问题 |
| M2 | 本地素材管理 + 自动归档    | 按剧本/分镜/集自动组织本地文件，支持拖入导入              |
| M3 | 对接外部视频生成大模型      | Provider 抽象层，首版对接 2 家（如可灵 + 即梦）      |
| M4 | 任务编排引擎           | 参数封装自动化、异步任务跟踪、结果回填、批量抽卡 + 结果对比      |
| M5 | 节点画布编辑           | 剧本节点/分镜节点/角色节点/任务节点 + 关系连线 + 分组拖拽    |
| M6 | 视频裁剪 + 字幕/气泡     | 基础时间轴 Trim/Split + 漫画对话框/旁白气泡叠加层     |
| M7 | 配音/音效            | AI 配音接入 + 音效匹配 + 音画对齐（成片闭环必需）        |
| M8 | 外部模型账号管理         | API Key 绑定 + 用量统计/调用历史/错误日志          |

### V2（二期）—— 进阶精修与工业化

| 序号 | 能力            | 说明                            |
| -- | ------------- | ----------------------------- |
| V1 | 视频微调（涂抹/文本描述） | 等外部模型 mask/video-edit 能力成熟后接入 |
| V2 | 多轨剪辑器         | 完整 NLE 时间线（多视频轨/多音频轨/转场/特效）   |
| V3 | 可视化 Agent 工作流 | 类 Dify 节点式自动化编排，支持自定义 Agent   |
| V4 | 成片导出/发布       | 多格式导出、平台适配（竖屏/横屏/多比例）         |

## 竞品对标

| 竞品        | 定位                      | 我们的差异                  |
| --------- | ----------------------- | ---------------------- |
| 万兴剧厂      | 企业级 SaaS，定价不透明          | 本地桌面端，个人/小团队友好         |
| Jellyfish | 开源 Web 部署，需 Docker/技术背景 | 零门槛安装，桌面 App 开箱即用      |
| AniShort  | 协作 SaaS + 节点画布          | 本地优先 + 更深度的漫剧业务画布      |
| Toonflow  | 开源桌面端，功能浅（无剪辑/无画布）      | 完整闭环：画布 + 剪辑 + 配音 + 治理 |

***

## 设计约束

* 本地数据为主，仅在调用外部模型 API 时联网

* 桌面端形态（Electron / Tauri 待定）

* 模型无关：任何暴露 HTTP API 的视频/图片/音频模型均可接入

* 首版面向单人使用，V2 考虑轻量协作
